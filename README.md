## About this repository

The site is a single page built with plain HTML, CSS, and JavaScript. It has no framework, no build step, and no backend, and it is hosted on GitHub Pages from the `main` branch.

```
index.html              Page content and sections
assets/css/style.css    Layout, colours, animations
assets/js/main.js       Scroll progress, reveal-on-scroll, mobile menu, contact form
assets/fonts/           Bowlby One + Sora
assets/images/          Favicon, game covers, app icons
assets/videos/          Hero gameplay video
assets/documents/       CV (PDF)
```

### Run locally

```
python -m http.server 5500
```

Then open http://127.0.0.1:5500.

### Deploy

Push to `main`. GitHub Pages publishes the change to https://shahzaibali0.github.io within a minute or two.
